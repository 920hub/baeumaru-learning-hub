허브와 일본어 학습

이름·학번·로그인을 요구하지 않습니다. 즐겨찾기와 학습 진도는 현재 브라우저의 로컬 저장소에 남습니다. 브라우저 데이터 삭제 또는 학습 진도 초기화로 지울 수 있습니다. 별도 분석·광고 도구는 사용하지 않습니다. 일본어 듣기는 기기에 설치된 일본어 음성이 있을 때만 제공합니다.

Google 로그인과 일기

Google/Firebase Authentication이 로그인 식별자와 Google 계정 기본 프로필 정보를 처리합니다. 앱은 로그인한 사용자의 UID를 데이터 접근에 사용하며 별도 사용자 프로필 문서를 만들지 않습니다. 로그인 상태는 현재 브라우저 세션에 유지됩니다.

작성한 날짜·제목·본문·기분·즐겨찾기·생성 및 수정 시각은 Google Cloud Firestore의 서울 리전(asia-northeast3)에 저장됩니다. 앱 이용자는 본인 기록만 읽고 변경할 수 있습니다. 운영자의 프로젝트 관리자 권한은 별도로 존재하므로 종단간 암호화 일기장은 아닙니다. 계정 식별 정보 등 인증 서비스의 모든 데이터가 서울에만 저장된다는 뜻은 아닙니다.

일기는 직접 삭제할 때까지 저장됩니다. 일기 상세 화면에서 삭제하고, 삭제 전 JSON 백업을 받을 수 있습니다. 로그아웃하거나 계정을 바꾸면 화면·메모리의 일기와 임시 작성 내용을 비웁니다. 본문을 브라우저 영구 캐시에 저장하지 않습니다. 직접 내려받은 백업 파일은 이용자가 관리해야 합니다. 기존 로컬 일기장은 자동 업로드하지 않습니다.

외부 서비스와 문의

정적 페이지는 GitHub Pages, 인증·DB와 SDK 전송은 Google Firebase 서비스를 사용합니다. 각 제공자는 서비스 제공을 위한 접속 정보 등을 처리할 수 있습니다. GitHub 개인정보 안내 · Firebase 개인정보 안내.

운영 문의는 프로젝트 이슈에서 받을 수 있습니다. 공개 이슈에 일기 내용·이메일·로그인 토큰을 게시하지 마세요. 계정 삭제 등 비공개 정보가 필요한 요청은 먼저 비공개 연락 경로를 요청해 주세요.
