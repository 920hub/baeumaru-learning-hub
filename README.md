# 배움마루

여행 일본어와 개인 일기를 담은 확장 가능한 정적 웹앱 허브입니다. Apple Music의 사이드바와 카드 중심 구성을 참고하되 이름·그림·콘텐츠는 새로 만들었습니다.

- 일본 여행 첫걸음: 6단계·24문항, 해설·재도전·단계 해제·240 XP. 로그인 없이 브라우저에만 진도를 저장합니다.
- 하루의 조각: Google 로그인 후 본인 UID 아래의 일기만 조회·작성·수정·삭제·JSON 백업합니다. 원래 로컬 일기장 데이터는 복사하거나 자동 이전하지 않습니다.

## 실행과 확장

Node 24, Java 21 권장. `npm ci --ignore-scripts`, `npm test`, `npm run check:public`, `npm run test:rules`로 검증합니다. `npm run serve`는 http://127.0.0.1:4175 에서 site 폴더만 제공합니다.

새 도구는 `site/apps/도구명/`에 넣고 `site/assets/catalog.js`에 ID, 제목, 분류, 링크, 그림, 검색어를 추가하면 검색·필터·즐겨찾기에 반영됩니다. 상대 경로를 사용하여 GitHub Pages 하위 경로에서도 작동합니다.

## 배포와 데이터

GitHub Actions는 테스트 및 규칙 에뮬레이터 검증 후 site 폴더만 Pages에 게시합니다. Firebase 규칙 배포는 별도이며 소유자의 Firebase CLI 인증이 필요합니다. `npx firebase deploy --only firestore --project baeumaru-diary-920hub-261110`로 named database `diary`에 적용합니다. DB는 서울(asia-northeast3)의 Enterprise Native 무료 등급이며 결제를 연결하지 않았습니다.

기존 일기장 검색·달력·기분 필터가 이미 읽은 항목에 즉시 적용되도록 Firestore Core SDK와 메모리 캐시를 사용합니다. 브라우저 영구 캐시에 일기 내용을 저장하지 않고, 새 조회와 저장 확인에는 서버 연결이 필요합니다. 목록은 한 번에 100개, 최대 500개를 불러오며 JSON 백업은 전체 최대 10,000개입니다. 여러 탭의 본문 동시 수정에는 마지막 저장이 적용됩니다. 즐겨찾기는 최신 서버 문서의 해당 필드만 갱신합니다.

Firebase 웹 설정의 API 키는 프로젝트 식별자이며 관리자 비밀키가 아닙니다. 권한 경계는 UID 기반 Firestore 규칙입니다. 인증 토큰·OAuth 비밀키·개인 일기·로컬 DB·개인용 Auth 설정은 저장소에 포함하지 않습니다. Google 로그인 공급자 및 허용 도메인은 관리 콘솔에서 설정하며 계정 자격증명을 CI에 넣지 않습니다.

## 보안 검증 범위

서로 다른 사용자와 비로그인 요청 차단, 생성/수정 스키마, 서버 시각, 최대 길이, 100개 조회 제한, 계정 전환 중 비동기 응답 차단, XSS 텍스트 렌더링, 저장 실패/재시도, 즐겨찾기 충돌을 테스트합니다. 에뮬레이터는 Standard 엔진으로 규칙을 검증하므로 실제 Enterprise 서버의 로그인·조회 동작은 별도로 확인해야 합니다. 공개 웹앱은 누구나 Google 계정을 만들 수 있어 계정별 문서 총량 제한·자동 남용 방지가 완전하지 않습니다. 비밀 기록의 유일한 백업 용도로 사용하지 마세요.
